# Data request emails

## How to use these drafts

Fill all placeholders and send from an institutional address. For the NIOT email, attach the supplied draft data-rights clause; it is not legal advice and should be adapted by a lawyer before use. Do not treat a licence clarification request as permission to use the data commercially.

Log each request and reply in the tracking table below, using the columns: dataset, sent date, contact, status, reply summary.
